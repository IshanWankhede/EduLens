# Reproducible example analysis

This example was generated by running the EduLens data loader and analysis functions against the
cleaned, local `student-por.csv` bundle. The output below is rounded for readability; all reported
values were computed by the code in this document.

## Data and parameters

- File: `student-por.csv`; cleaned analysis frame: 649 rows.
- Performance bands: Low `G3 < 10`, Medium `10 <= G3 <= 13`, High `G3 >= 14`.
- High-performance event threshold: `G3 >= 14`, read from `src.config.PERFORMANCE_BANDS`.
- Probability comparison event: `studytime >= 3`.
- Confidence level: 0.95; test alpha: 0.05.
- Classification: stratified 20% holdout, five-fold stratified cross-validation, seed 42.
- OLS: G3 outcome; numeric-coded ordinal predictors `studytime`, `absences`, and `failures`.

### Conditional probability and Bayes

Let A be high performance (`G3 >= 14`) and B be `studytime >= 3`. The common complete-case cohort
has `n=649`, `n(A)=194`, `n(B)=132`, and `n(A∩B)=58`.

- `P(A) = 194/649 = 0.2989`
- `P(B) = 132/649 = 0.2034`
- `P(A∩B) = 58/649 = 0.0894`
- `P(A|B) = 58/132 = 0.4394`; 95% Wilson interval: `[0.3576, 0.5246]`
- Bayes walkthrough: prior `P(B)=0.2034` → likelihood `P(A|B)=0.4394` → evidence `P(A)=0.2989`
  → posterior `P(B|A)=58/194=0.2990`.

The posterior agrees with the direct frequency `n(A∩B)/n(A)`, up to displayed rounding.

### Hypothesis tests

The two-group Welch t-test compares G3 for `studytime < 3` (`n=517`) versus `studytime >= 3`
(`n=132`): `t=-5.8930`, `df=245.1765`, `p=1.2469e-08`, mean-difference 95% CI
`[-2.1369, -1.0662]`, Cohen's `d=-0.5055`. At `alpha=0.05`, the computed decision is sufficient
evidence against the equal-means null for this comparison.

The one-way ANOVA across observed studytime levels reports `F(3, 645)=15.8763`, `p=5.7057e-10`,
and `eta-squared=0.0688`. Group mean G3 and 95% confidence intervals:

## Reproduction code

Run from the repository root with the project environment. This uses the application's own
loading, cleaning, descriptive, association, probability, inference, regression and prediction
functions; it does not hard-code the reported results.

```python
from src import config
from src.correlation import ranked_associations
from src.data_loader import load_uci_dataset
from src.descriptive_stats import summary_table
from src.hypothesis_tests import independent_t_test, one_way_anova
from src.prediction import compare_models
from src.probability import (
    EventCondition,
    bayes,
    conditional_probability,
    high_performance_event,
)
from src.regression import fit_ols

data = load_uci_dataset("por").clean
summary = summary_table(data, ["G3", "absences", "studytime"])
associations = ranked_associations(
    data, "G3", ["G3", "G1", "G2", "studytime", "absences", "failures"]
)

event_a = high_performance_event()
event_b = EventCondition("studytime", ">=", 3)
probability = conditional_probability(data, event_a, event_b)
bayes_result = bayes(data, event_a, event_b)

t_test = independent_t_test(
    data.loc[data["studytime"] < 3, "G3"],
    data.loc[data["studytime"] >= 3, "G3"],
    alpha=config.DEFAULT_ALPHA,
    confidence_level=config.DEFAULT_CONFIDENCE,
)
anova = one_way_anova(
    data, "G3", "studytime",
    alpha=config.DEFAULT_ALPHA,
    confidence_level=config.DEFAULT_CONFIDENCE,
)
ols = fit_ols(
    data, "G3", ["studytime", "absences", "failures"],
    confidence_level=config.DEFAULT_CONFIDENCE,
)
models = compare_models(
    data,
    test_size=config.DEFAULT_TEST_SIZE,
    cv_folds=config.DEFAULT_CV_FOLDS,
    seed=config.RANDOM_SEED,
)

print(summary.table)
print(associations.table)
print(probability)
print(bayes_result)
print(t_test)
print(anova)
print(ols)
print(models)
```
