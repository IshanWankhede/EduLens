# Manual screenshot checklist

Capture screenshots from the running app yourself; no screenshots are included or synthesized.
Save the unedited captures in this directory using these exact filenames:

1. `01-overview.png` — Overview hero, computed metrics, and the “How EduLens Works” strip.
2. `02-dataset-explorer.png` — Portuguese dataset preview, column information, and cleaning
   summary.
3. `03-descriptive-statistics.png` — selected G3 summary and group-summary table.
4. `04-exploratory-analysis.png` — one titled distribution chart with its reading caption.
5. `05-correlation.png` — labelled correlation heatmap and ranked target associations.
6. `06-probability-bayes.png` — conditional-probability cards and the prior/likelihood/evidence/
   posterior walkthrough.
7. `07-hypothesis-testing.png` — one completed test showing assumptions and the ordered result
   flow.
8. `08-regression.png` — coefficient interval table, assumptions, and regression diagnostics.
9. `09-prediction.png` — Model A input form, Low/Medium/High probability view, and disclaimer.
10. `10-model-evaluation.png` — confusion matrix, macro-F1 and baseline, CV spread, and model
    comparison.
11. `11-about.png` — methods, limitations, ethics, and dataset citation.

Use the supplied Portuguese dataset and include enough of each page to show its labels and
captions. Do not include uploaded personal or sensitive data. Add images to the README screenshot
table only after these manual captures exist.
